# GrandRide 🚗

A full-stack car rental and booking platform built with the MERN stack. GrandRide allows users to browse available cars, authenticate securely, and manage their car bookings through a responsive web interface.

## 🚀 Live Demo

[Visit GrandRide](https://grandride.vercel.app/)

## ✨ Features

- 🚗 Browse available cars
- 🔍 View car details
- 🔐 User registration and login
- 👤 User authentication with JWT
- 📅 Car booking system
- 📋 Manage bookings
- 📱 Responsive design
- ⚡ Fast and modern React interface
- 🔒 Secure backend API

## 🛠️ Tech Stack

### Frontend

- React.js
- Vite
- Tailwind CSS
- Axios
- React Router
- JavaScript

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- REST API
